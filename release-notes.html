  1. October 29, 2026Link to this release

    LastPass VPN Version 1.1.0

    • Smarter auto reconnect. With Auto reconnect on, LastPass VPN now waits and reconnects when the internet returns, and notifies you when you disconnect and reconnect. It also reconnects after a network adapter change or a connection timeout. The timeout pop-up is gone.
    • More launch control. Auto reconnect, Launch on startup, and Reconnect on launch are now 3 separate switches, all on by default. Launch on startup opens the app in the background when Windows starts. Reconnect on launch restores your last connection if you were connected when the app closed.
    • ARM64 driver support. The network driver now installs on ARM64 devices, laying the groundwork for features like split tunneling.
    • Smoother tray menu. The tray menu now grows upward in step with the card animations.
    • Clearer protocol settings. A new note explains that changing protocols disconnects you briefly, then reconnects you automatically.
    • Easier to find. LastPass VPN for Windows now has its own card, with a Microsoft Store link, on the LastPass Downloads page.
    • FixedFixed cut-off and crowded text in German, Spanish, French, Italian, and Portuguese.
  2. October 13, 2026Link to this release

    Admin Console Version 13.10.2026

    • NewAI Monitoring & Protect is now available in SaaS Protect. It provides visibility into AI applications being used across the organization and allow administrators to enforce usage rules directly through the browser. It also detects and warns users when they enter, paste, or upload sensitive data to AI tools.
    • NewAdmins can allow or deny exception requests for categories of apps on the SaaS Protect page.
    • NewAdmins can enable the automatic addition of newly discovered apps and sites to the app catalog as custom apps in SaaS Monitoring.
    • NoteInstall the latest LastPass browser extension to use these features. It is available for Chrome, Edge, and Safari. Firefox and Opera support is coming soon.
  3. October 12, 2026Link to this release

    Admin Console Version 12.10.2026

    • NewIntroduced Admin activity report event type “Activity report exported”. It appears in logs when either the User activity report or the Admin activity report is exported as a CSV file, with the report type specified in the “Event information” column. The new event only appears for export events that have happened on or after Oct 12, 2026.

  6. October 5, 2026Link to this release

    Admin Console Version 01.10.2026

    • ImprovedUI caption changes on the “Company profile” page, section “Subscription”: the header of the “Name” column became “Plan”, the original “Plan” became “Type”, and “Auto-renewal” became “Auto renew”.
  7. October 1, 2026Link to this release

    Admin Console Version 01.10.2026

    • ImprovedAdded an “Add users” button to the “License consumption rate” section of the Adoption dashboard (only for super admins, admins, and custom admins with the “Add & edit users” permission).
    • ImprovedThe “All users” tab and “Add users” drawer now show the number of total, used, and unused licenses. For Managed Service Providers (MSPs) it only shows the number of used licenses, since MSPs have no license limit.
    • ChangedThe header of the “User” column in the admin activity report changed to “Admin” in both the report page in the Admin Console and its CSV file export.
    • ChangedThe exported CSVs of user activity reports and admin activity reports now contain the full name of the events (instead of event ID names) when the CSV is sent through email.
    • ChangedThe file name scheme for the exported CSVs of user activity reports and admin activity reports have changed.
    • NewFor Managed Service Providers (MSPs) and sub account managers, a company filter became available in the admin activity report that can show admin actions that took place in each company (including the MSP itself or the selected managed company). Some filtered results are only available as a CSV file export. MSP / sub account manager custom admins need the “View managed companies” permission to see the new filter.
    • NewFor MSPs and sub account managers, the exported CSV of admin activity reports now start with the new “Affected company” and “Affected company ID” columns if the report was generated while the company filter was set to “All companies” or “Managed companies only”.
    • NewFor MSPs and sub account managers, the exported CSV of admin activity reports can now contain new event types: Advanced MFA enabled for company, Advanced MFA disabled for company, Company created, Company suspended, Company detached, and Admin accessed company. All but the last of these appear in reports retroactively starting from May 20, 2026, while Admin accessed company events appear from Oct 1, 2026.
